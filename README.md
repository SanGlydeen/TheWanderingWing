# The Wandering Wing

The site at [thewanderingwing.com](https://thewanderingwing.com) — aerial films
and photographs by Samuel Salesas.

Plain static HTML, generated by two small Python scripts. There is no Node, no
npm, and nothing to install: it runs on the Python and image tools that ship
with macOS, so it will still build years from now.

## How it works

Originals live in iCloud and are never touched:

    ~/Library/Mobile Documents/com~apple~CloudDocs/Files/Personal/Hobbies/
      Photography/Drone/The Wandering Wing/

Two commands turn them into a website:

    python3 photos.py    # resize originals into public/photos/  (slow)
    python3 build.py     # generate the HTML into public/        (instant)

`photos.py` reads each original once and writes JPEGs at 400/800/1400/2000/2400
pixels wide, recording the results in `photo-manifest.json`. It skips anything
already up to date, so re-runs take seconds. A 11 MB original becomes a 733 KB
full-size frame and a 101 KB thumbnail; the browser picks whichever size fits
the screen it is on.

`build.py` reads `content/` and writes the finished pages.

## Adding a place

1. Drop the photos into a new folder under `Posts/` in the iCloud library.
2. Add that folder to the `groups` dict at the bottom of `photos.py`.
3. Run `python3 photos.py` to generate the derivatives.
4. Create `content/places/<slug>.md`:

       ---
       title: Somewhere
       region: Country
       date: 2026-04
       hero: somewhere/dji-1234
       feature: 2            # optional: position on the homepage
       film: dQw4w9WgXcQ     # optional: YouTube id
       photos:
         - somewhere/dji-1234
         - somewhere/dji-5678
       ---
       A paragraph about the place.

5. Run `python3 build.py`, then commit and push. Cloudflare deploys the rest.

## Adding a film

Create `content/films/<n>-<slug>.md` with a `youtube:` id and a `poster:` image
key. Films are ordered by filename; the first one is the homepage feature.

Videos are hosted on YouTube and embedded behind a click-to-play poster, so no
YouTube script or cookie loads until a visitor actually presses play.

## Local preview

    python3 -m http.server 8788 --directory public

## Deployment

Cloudflare Pages builds nothing — it serves `public/` exactly as committed.
Pushing to `main` publishes.
